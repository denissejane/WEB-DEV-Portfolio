## 📌 Overview

Den’s World is my midterm activity for Comp 016 - Web Development. I started with my first activity, a web-based resume, and grew it into a little interactive world that shares more about me.

Visitors can explore my background, the communities I’m part of, events and memories, projects I’ve worked on, and ways to contact me. I wanted it to feel personal and fun, while still being easy to read and use on a phone or computer.

---

## 🗂️ File Structure

```text
dens-world/
├── index.html   # Page content and layout
├── styles/      # CSS files for colors, layout, cards, and details
├── js/          # JavaScript files for the site’s features
├── script.js    # Starts the features when the page is ready
├── org-icons/   # Organization and technology icons
├── photos/      # Portfolio photos
└── README.md    # Project notes
```

The CSS files load in numbered order so the styles stay in the right order. The JavaScript files are grouped by feature to make them easier to find and follow.

## 🛠️ Tech Stack

| Technology | How I used it |
|---|---|
| **HTML** | Built the page and added my portfolio content |
| **CSS** | Styled the islands, cards, colors, and phone layouts |
| **JavaScript** | Added navigation, theme changes, and other interactions |
| **Google Fonts** | Added Nunito and Press Start 2P to match the playful look |
| **No frameworks** | Made the site with plain HTML, CSS, and JavaScript |

## ✨ Features

- Five sections connected by a winding island path
- Navigation that follows along as visitors scroll
- Light and dark themes
- Layouts that fit phones and computers
- Expandable details, project displays, and a little flower garden
- Reduced motion options for visitors who prefer less animation

## 💡 A Few Things I Learned

- HTML, CSS, and JavaScript each have a different job, and they work together to make a webpage.
- Small JavaScript features can make a portfolio more fun to explore.
- A page needs to be planned for small screens as well as big ones.
- Splitting CSS and JavaScript into smaller files makes a growing project easier to work on.
- Trying changes as I build helps me notice what needs fixing.

## 🌱 Reflections

### On Building Den’s World
Turning my first web-based resume into a bigger portfolio gave me a chance to bring together what I’ve been learning about web development. I got to shape the page around my own stories, projects, and interests, and make it feel like a small world visitors can explore.

### On Learning Web Development
This activity helped me understand how the parts of a website fit together. I learned more by building and changing the page than I would by only reading about the code. There’s still more I want to learn, and this project gave me a fun place to start.

### Little Takeaways
- Keep the code organized as a project grows.
- Check how the page looks on different screen sizes.
- Try things, notice what happens, and keep learning as you go.
